# 热血传奇 TUI 挂机（r-chuanqi）

终端里的挂机 / 增量游戏。职业、怪物、地图和装备取自传奇 1.67，赤月和牛魔这段顶级内容取自 1.76。数值按成长曲线估算，不是客户端原始表 —— 全部内容都在 `data/*.ron` 里，改数据不用改代码。

**想先看这游戏是什么样、玩什么？→ [游戏简介](INTRO.md)**

## 运行

需要 Windows Terminal，或别的支持 Unicode 和真彩色的终端。旧版 `cmd.exe` 里中文宽度和颜色会错。完整界面要求窗口至少 80×24。

```bash
cargo run -p r-chuanqi                                   # 启动游戏
cargo run -p r-chuanqi --bin sim -- --class warrior --ticks 36000 --seed 42
cargo run -p r-chuanqi --bin check-content               # 内容表体检
```

### 安装发布包

发布包是安装程序，不是解压即用的压缩包。下载 [**r-chuanqi-setup-x86_64-pc-windows-msvc.exe**](https://github.com/runbrick/tui-chuanqi/releases/download/v1.1.1/r-chuanqi-setup-x86_64-pc-windows-msvc.exe) 双击运行：

- **Windows**：装到 `%LOCALAPPDATA%\Programs\r-chuanqi`，写入用户 PATH，开始菜单和「设置 → 应用」里留下入口
- **其它系统**：装到 `~/.local/share/tui-game`，命令放在 `~/.local/bin/r-chuanqi （目前没有测试，如果有问题请提 issues）`

新开一个终端直接运行 `r-chuanqi`，或从开始菜单打开（已经开着的终端不会变）。

卸载运行 `r-chuanqi uninstall`（安装程序也可以加 `uninstall`）：从 PATH 拿掉命令，删掉程序目录，**存档留下**。

### 发布

推送 `vX.Y.Z` 标签会跑 `.github/workflows/release.yml`，为 Windows、Linux、macOS 打包并发布到 GitHub Releases。标签已存在时，也可以在 Actions 里手动跑 release，填同一个标签。

### 模拟器 sim

`sim` 不画界面，用来看等级、金币和击杀，是调平衡的主要工具：

- `--class warrior|mage|taoist`
- 默认是建号后什么都不做的纯挂机
- `--bot`：模拟一个会回城补药、买书、换装、开自动推进的玩家，打印每级用时和每张图的停留时间、死亡数
- `--trace`（配合 `--bot`）：统计每种技能放了多少次、喝了多少药

调 `data/*.ron` 的数值时用 `--bot` 对比三个职业。

## 操作

启动后是角色列表：`N` 创建，`D` 删除（要再输入一次名字），Enter 进入。


| 键         | 作用                                              |
| --------- | ----------------------------------------------- |
| 1–6 / Tab | 战斗、背包、技能、地图、商店、统计。也可以点底部标签                      |
| ↑↓ Enter  | 选择、使用、穿戴、进图。列表到头会绕回，Home/End 跳到头尾。战斗和统计面板里用来翻日志 |
| 鼠标        | 滚轮选择或翻日志，点一行选中，再点一次等于 Enter                     |
| E         | 背包里切到「身上的装备」：Enter 脱下，L 锁定                      |
| L         | 锁定。锁住的东西不会被卖掉、不会被拿去当升级材料，高风险死亡也不掉               |
| X / R / F | 卖白装、修理、按职业把红蓝药补满（钱不够时两边轮流买）                     |
| A         | 自动推进。4 级之后才能开。只沿主线走，BOSS 支线要手动进                 |
| P         | 开关自动吃药                                          |
| `[` `]`   | 调低、调高喝血线。显示的是剩余多少血                              |
| `-` `=`   | 调低、调高喝蓝线。显示的是剩余多少蓝                              |
| U         | 武器升级。先显示成功率和会消耗的材料，再按一次才执行，按别的键取消               |
| F3        | 下载并安装新版本；失败后按 F3 重试                             |
| ? / F1    | 帮助                                              |
| F2        | 伪装成时钟，再按一次恢复                                    |
| Q         | 保存并退出                                           |


快捷键不分大小写，中文输入法开着时按出的全角标点（【】—）也认。商店和出售的数量框里可以直接输数字，↑↓ 加减 1，PgUp/PgDn 加减 10，End 或 M 取最多。

## 角色与存档

- 职业、性别、高风险在创建时选定，之后不能改。高风险掉落 +50%，死亡会掉一件没锁定的装备
- 存档默认在 `%APPDATA%\tui-mir\`（其它系统用 `directories` 的数据目录）。每个角色一个槽位目录，同名可以同时存在
- 离线收益只结算正在进入的那个角色，最多累计 12 小时。逻辑 tick 是 100 毫秒，离线就是快放同一套 tick

## 挂机行为

- 死亡或没药回城后，休息完会自己回到原来的图。同一级里连死 3 次会退回上一张图，升级后自动推进再往前走。自己手动换图就不再自动回去
- 正式版启动后会后台查 GitHub Releases，有更新时底部提示，按 `F3` 下载对应平台安装包并重启。下载在后台进行，游戏照常运行，底部提示栏显示进度条、百分比和已下载大小；装好后提示「下载并安装成功，正在重启」，约 1.5 秒后自动退出换上新版本。下载失败会提示原因，再按 `F3` 重试。存档不会被替换。仓库默认是 `runbrick/tui-chuanqi`，编译时可以用 `TUI_GAME_REPO=owner/name` 覆盖。`cargo run` 的调试构建不检查更新
- 游戏中窗口小于 80×24 时只显示挂机信息：角色、血蓝、经验和升级预计、当前地图战况、提醒，剩下的行给最新日志。按键照常生效，窗口放大后自动恢复。选角、创建这些界面太小时仍提示放大

## 目录

- `crates/game-data`：RON 类型、加载和校验
- `crates/game-core`：状态、战斗、掉落、存档结构。这里不能依赖终端
- `crates/game-tui`：界面和槽位存档
- `data/`：内容表。怪物、物品、技能、地图、NPC、平衡系数都在这里
- `doc/`：设计文档（见 [doc/README.md](doc/README.md)）
