# 1.67 内容清单（草稿）

> ## ⚠️ 先读这段
>
> 1.67 是 2002–2003 年前后的版本。现存网络资料大量混入了 1.76 / 1.80 / 后期私服的内容，彼此矛盾。这份清单是**按版本演进逻辑整理的草稿**，不是权威考据。
>
> - `✅` = 基本确定属于 1.67 或更早
> - `⚠️` = 存在于传奇系列，但**是否在 1.67 中存在不确定**（可能是 1.76+ 才加入）
> - 数值（HP / 攻击 / 掉率）**全部是我按曲线推的，不是原作数据**，需要你用 `sim` 工具调
>
> **建议做法**：先用这份草稿把系统跑通（T2–T9），内容正确性留到 T15 再集中处理。那时你可以去找 1.67 的客户端资源文件或老玩家社群核对，直接替换 RON 文件即可，不用改一行代码。
>
> **最可靠的考据来源**：1.67 版本的客户端数据文件（`Mir2/Data/` 下的 `.db` / `MonItems` / `StdItems` 等），里面就是原始数值表。如果你能找到老客户端，这份文档可以整体作废。

## 内容填充工作流（给 T15 用）

1. 先按**等级区间**横切，不要按类型纵切。即："把 Lv.20–30 的怪 / 装备 / 地图 / 技能一次填完"，而不是"把所有怪填完再填装备"。这样每填一段就能立刻用 `sim` 验证那一段的体验。
2. 每填完一个区间，跑 `cargo run --bin check-content` 找空洞。
3. 数值不要手填，写个 spreadsheet 或脚本按曲线生成基线，再手工调整有特色的条目（BOSS、经典装备）。
4. 掉落率先按"期望获取时长"反推：想让玩家 40 分钟拿到祖玛头盔，就按那张地图的击杀速度算掉率，而不是凭感觉填 `0.015`。
